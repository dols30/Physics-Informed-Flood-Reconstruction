# Showcase notebook results

These CSVs were regenerated by executing the attached showcase notebook in a fresh
Python 3.13.3 environment from an isolated ZIP-extracted project. The tables matched
the original execution within floating-point tolerance. The notebook itself remains
byte-for-byte identical to the submitted attachment.

- `validation_results.csv`: wave 1 model-selection metrics.
- `test_results.csv`: held-out wave 1 reconstruction metrics, WSE errors in mm.
- `wave3_transfer_results.csv`: frozen wave 1 models evaluated on wave 3, WSE errors in mm.
- `synthetic_results.csv`: dimensionless depth/discharge errors and physics residuals.

Source measurements are from Segovia-Burillo et al.,
[Zenodo 17777387](https://zenodo.org/records/17777387),
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Processing and units are documented in [data provenance](../../docs/data_sources.md).
Full verification details are in [reproducibility evidence](../reproducibility.json).
